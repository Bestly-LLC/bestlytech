## Tailoring rules

1. **Never fabricate.** Only reuse facts on this page. If a posting wants a tool or
   credential he lacks (Opera PMS, Go Concierge, a conferred degree, a specific
   certification), do not claim it. Write "fast to learn new [category] systems" instead.
2. **Never inflate a commitment.** See the Availability section. This applies to hours,
   travel, relocation, on-call, and start date.
3. **Reverse-chronological, always.** Keeps ATS parsers happy. Do the repositioning in
   the Summary, the tagline, and a highlights block near the top — not by reordering jobs.
4. **Match the tagline to the target title.** The line under his name changes per
   application (e.g. "GUEST SERVICES • FRONT OFFICE • LUXURY HOSPITALITY").
5. **Address the overqualification objection head-on** for hourly, part-time, or
   individual-contributor roles. Add a note under Bestly LLC that it continues as a
   part-time venture and he is actively seeking the target role. Without this, strong
   resumes get passed over as flight risks.
6. **Lead with the relevant era.** For hospitality → Disney + Expedia. For SaaS/CS →
   Expedia + Lucid + Bestly. For ops/PM → Disney + Lucid systems work + Bestly funnel.
7. **Two pages is fine.** Ten-plus years justifies it. Don't cram to one page.
8. **No near-duplicate bullets.** If an item appears in both a highlights block and the
   job entry, the two must say different things — one the outcome, one the ownership.
9. **What Claude must not fill in on applications:** Social Security number, government
   ID, bank details, passwords, date of birth, and EEO/demographic self-identification
   (race, gender, veteran status, disability). Leave EEO blank or select
   "decline to self-identify," and tell Jared so he can set it himself.

## Self-check before delivering

Run all three greps over the generated file and print the surrounding sentence:

1. **Employer names** — confirm each accomplishment sits under the correct job.
2. **Every metric** — confirm each number is attached to the employer it came from.
3. **`overnight|fully open|any shift|24/7|relocat|travel`** — confirm no commitment
   appears that Jared did not personally state.

Catching either a mis-attribution or an over-commitment after Jared has already sent the
resume is the failure mode that matters. He should not have to be the one to find these.
